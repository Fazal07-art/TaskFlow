# 🚀 TaskFlow – Modern Task Management

TaskFlow is a modern full-stack task management web application designed to help users efficiently organize, manage, and track their tasks.

The application provides a clean and user-friendly interface for creating an account, securely logging in, creating tasks, updating task status, and managing daily work from a centralized dashboard.

## 🌐 Live Demo

👉 **[Open TaskFlow](https://task-flow-mu-rose.vercel.app/login)**

## ✨ Features

- 🔐 User Registration and Login
- 🔑 JWT-based Authentication
- 📝 Create and Manage Tasks
- ✏️ Edit Task Details
- 🗑️ Delete Tasks
- ✅ Update Task Status
- 📊 Task Management Dashboard
- 🔒 Protected API Routes
- 📱 Responsive User Interface
- ⚡ Fast and Modern Vite Frontend
- ☁️ Cloud-hosted Full-Stack Application
